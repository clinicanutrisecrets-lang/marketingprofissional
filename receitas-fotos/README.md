# 📸 Biblioteca de fotos de receitas

Jogue aqui as fotos das receitas terapêuticas (JPG, PNG ou WebP).

**O nome do arquivo vira o título do post:**

```
torta-de-cacau-com-abacate.jpg  →  "Torta de cacau com abacate"
panqueca-de-banana-verde.jpg    →  "Panqueca de banana verde"
caldo-de-ossos-com-curcuma.png  →  "Caldo de ossos com cúrcuma"
```

Regras:
- nome em minúsculas, palavras separadas por hífen, sem acentos
- foto na vertical ou quadrada fica melhor (a arte corta pra 1:1/4:5)
- ao fazer push na main, o GitHub Action `Sync Receitas` sobe tudo
  automaticamente pro banco — e as receitas passam a aparecer nas
  sugestões semanais de todas as franqueadas, adaptadas ao nicho de cada
  uma (ex.: "para quem tem Hashimoto", com genes/microbiota na legenda).
